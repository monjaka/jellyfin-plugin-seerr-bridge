Jellyseerr Bridge

The address the Jellyfin server uses to reach Jellyseerr, including the port. If Jellyfin runs in Docker, don't use localhost: inside the container it means Jellyfin itself. Use the Jellyseerr container name (for example http://jellyseerr:5055) or the server's LAN IP.
Stored on the Jellyfin server and only used there. Once saved, it isn't shown again: leave this blank to keep the saved key, or type a new one to replace it.
Leave disabled until you have tested search and configured Jellyseerr.
Requests from any user go straight to Radarr or Sonarr, even if their Jellyseerr account would normally wait for an admin. Request limits set in Jellyseerr still apply.
When someone without a Jellyseerr account makes their first request, import them from Jellyfin with Jellyseerr's default permissions. Turn this off to choose who gets an account yourself, in Jellyseerr under Users, Import Jellyfin Users.
Optional. One Jellyfin user ID per line. Only these users can request titles or report problems. Leave empty to allow every signed-in Jellyfin user.
